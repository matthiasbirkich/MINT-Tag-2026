SOM und SOC aus Bodenfarbe abschätzen

Literaturbasierte Bereiche aus Munsell Value und Textur, keine Kalibration an euren Bodenproben. Bereiche sind keine Konfidenzintervalle.

Farbe liefert hier eine grobe Orientierung. Eisenoxide, Sulfide, Feuchte und Ausgangsmaterial beeinflussen sie ebenfalls. Besonders bei stark gefärbten und tropischen Böden ist die Übertragbarkeit begrenzt. Für eure Proben fehlen unabhängige SOM-/SOC-Referenzanalysen.

Unterschiedlich gefärbte Bodenproben vergleichen

Eine Probe vollständig auswerten und speichern, dann unter „Bodenmessung“ eine neue Probe beginnen. Gespeicherte Ergebnisse bleiben erhalten. Jede Zeile enthält die verwendeten Annahmen.

Messstreuung und Literatur-Schätzbereiche beantworten verschiedene Fragen. Unterschiede der Schätzwerte bestätigen keinen tatsächlichen SOC-Unterschied.

Kurzanleitung

  1. In Nix Toolkit C / 2° / M2 einstellen. Dasselbe Farbfeld der Kontrollkarte messen und unter „Referenzprüfung“ vergleichen.
  2. Bodenprobe trocknen, homogenisieren und eine ebene Oberfläche herstellen. Fünf Messungen aufnehmen und unter „Bodenmessung“ eintragen. Die Messöffnung vollständig bedecken.
  3. „Auswerten“ zeigt Statistik und Munsell. Für SOM/SOC Textur, Zustand und Material angeben. Bei unbekannter Textur erscheinen drei ausdrücklich hypothetische Szenarien.
  4. Probe zum Vergleich hinzufügen. Vor der nächsten Probe „Neue Bodenprobe“ wählen. Zum Abschluss CSV und eine vollständige JSON-Sicherung exportieren.

Was wird berechnet?

CIELAB unter C / 2° wird in XYZ (0–100) umgerechnet. Wie in Swift v0.1.8 erfolgt die Munsell-Auswertung aus dem XYZ-Mittelwert. Einzelne L*, a*, b* werden zusätzlich mit Mittelwert und Stichproben-SD ausgewertet. Munsell-Chips stammen aus den Renotationsdaten der angehängten Swift-App: Bodenfarbtöne 10R bis 5Y, Chroma 1–8, Value 2–8 sowie Neutralgrau Value 2–9. Es ist keine vollständige Munsell-Farbsammlung. Zwischenstufen werden wie in Swift interpoliert. Der kontinuierliche Farbton ist eine Näherung aus sechs Nachbarn. Große ΔE00-Abstände zeigen eine schwache Zuordnung an.

SOM-Bereiche folgen der Trockenboden-Spalte der FAO-Tabelle 46. Im FAO-Modus wird bei Chroma 3,5–6 der Value um 0,5 erhöht, bei Chroma über 6 um 1,0. Danach wird auf die nächste halbe Stufe gerundet (eine Verfahrensentscheidung der App). Außerhalb Value 2,5–7 wird im FAO-Modus nicht extrapoliert. Der Swift-Modus übernimmt das Verhalten von v0.1.8: keine Chroma-Korrektur und Begrenzung heller Werte auf Tabellenstufe 7. Für Value 2,5 gibt es nur für Sand einen Trockenboden-Eintrag.

SOC ≈ SOM × 0,58 (umgekehrte van-Bemmelen-Konvention), jeweils Massen-% bezogen auf trockenen Boden. Die Spannen sind Tabellenklassen, keine gemessene Genauigkeit. Ohne Boden-Referenzanalysen lässt sich das Verfahren hier weder kalibrieren noch validieren. Glühverlust ist ebenfalls eine indirekte Bestimmung organischer Substanz; seine Aussage hängt von der Methode und der mineralischen Matrix ab.
